# Generadores iniciales archivados

Estos archivos son antecedentes de la creación del proyecto. Su contenido se conserva íntegro, con extensión `.py.txt` para distinguirlos de los scripts operativos.

- `setup_backend.py.txt` generaba copias antiguas del backend en una ruta fija de otra instalación.
- `setup_tests.py.txt` generaba copias antiguas de las pruebas en esa misma instalación.

No forman parte de la preparación actual: ejecutarlos podría sobrescribir código. Utilizar [scripts/setup.ps1](../../../scripts/setup.ps1) y la [guía de instalación](../../installation.md).
